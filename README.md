# 🏆 Telegram-бот учёта активности и рейтинга студентов

Современный Telegram-бот для геймификации и автоматизации учета турнирной таблицы лидеров.

---

## 🚀 Установка и быстрый старт

1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Настроить переменные окружения `.env`
4. Запустить: `python bot.py`
